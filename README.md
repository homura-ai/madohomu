# MadoHomu

[Install MadoHomu](https://github.com/homura-ai/homucode/blob/main/docs/user/duet.md#install-madohomu)

MadoHomu is a thin launcher for Duet, HomuCode’s focused Chat and Tasks view. It depends on [HomuCode](https://github.com/homura-ai/homucode) and shares its server, threads and settings. The implementation and installer live in HomuCode; this repository is only the installation entry point.

The Linux installer downloads the latest HomuCode AppImage release. Source builds can use an existing AppImage via `MADOHOMU_RUNTIME`; see the install guide for details.
