# MadoHomu

[Install MadoHomu](https://github.com/01-1/homucode/blob/main/docs/user/duet.md#install-madohomu)

MadoHomu is a thin launcher for Duet, Homu Code’s focused Chat and Tasks view. It depends on [Homu Code](https://github.com/01-1/homucode) and shares its server, threads and settings. The implementation and installer live in Homu Code; this repository is only the installation entry point.

Duet is being prepared in Homu Code. The install link becomes available when that change is published. A downloadable runtime also requires a Homu Code release; source builds can use an existing AppImage.
