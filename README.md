# MadoHomu

MadoHomu is a focused workspace for one project in [HomuCode](https://github.com/homura-ai/homucode).

Open **Settings → Homu Code → MadoHomu** to choose a project. To add a separate launcher,
use the desktop app toggle in MadoHomu settings or follow the Linux installer instructions.
